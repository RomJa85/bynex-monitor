# История изменений BYNEX Monitor

Все заметные изменения проекта фиксируются здесь в обратном хронологическом порядке.
Техническая история каждого изменения и возможность вернуть прежнее состояние хранятся в Git-истории репозитория.

## [Unreleased]

### 2026-11-26 — Стабилизация получения стаканов

- В браузере введена единая очередь запросов за стаканами, общая для карточек мониторинга и ручного арбитража.
- Ограничено число одновременных запросов из браузера: не более 3.
- Добавлены повторные попытки при временных сетевых ошибках, тайм-аут одного запроса — 12 секунд.
- Повторные запросы одной и той же пары объединяются: используется один выполняющийся запрос.
- На Python-сервере добавлено общее ограничение до 3 одновременных обращений к API BYNEX. Оно применяется как к запросам браузера, так и к фоновому мониторингу.
- Ручной арбитраж больше не прекращает анализ из-за единичной ошибки получения стакана: анализирует успешно полученные пары и показывает предупреждение о недоступных парах. Для анализа требуется минимум 3 полученных стакана.

Изменения:
- `index.html` — коммит [b787b115](https://github.com/RomJa85/bynex-monitor/commit/b787b1159a496b06cc9ed6559bbd15bb2f125926)
- `server.py` — коммит [c0a9d2d4](https://github.com/RomJa85/bynex-monitor/commit/c0a9d2d431dd18b2dc88789e4e3d91bc43e3c071)

Статус проверки: изменения опубликованы в GitHub; проверка под реальной нагрузкой на работающем сервере ещё требуется.

### 2026-11-25 — Telegram-уведомления и стартовые активы арбитража

- Исправлено форматирование Telegram-уведомления контроллера: вместо буквальных символов `\\n` используются реальные переносы строк.
- В уведомление об арбитражной возможности добавлены цены, по которым рассчитан каждый шаг маршрута.
- Вместо одного стартового актива в настройках арбитража поддерживается список стартовых активов с отдельными валютами и суммами.
- Ручной и серверный автоарбитраж учитывают несколько стартовых активов и выбирают наиболее выгодный найденный маршрут.
- Для конфигурации сохранена совместимость со старыми параметрами одного стартового актива.

Изменения:
- `index.html` — коммиты [3acba4d](https://github.com/RomJa85/bynex-monitor/commit/3acba4d2516c9f06c7aa7c89a1482dfdbde55993) и [04250a6](https://github.com/RomJa85/bynex-monitor/commit/04250a67d599d6accb61fd74f90449b749148d35)
